## Windows that grow during a call

- A window is now recorded into a fixed 1920×1080 frame, its picture fitted inside with black around it. Before, a recording kept the window's size at the start: a Slack huddle started as a thin strip recorded the screen share that followed only 332 pixels high.
- Display recordings keep the display's own size.

## Downloads

- **AnyRec-0.8.3.zip**: Mac app for Apple Silicon and Intel.
- **anyrec-0.8.3-universal.tar.gz**: command-line tool with its embedded Whisper framework.
- **SHA256SUMS**: checksums of both downloads.

Both downloads are Developer ID signed and notarized. Requires macOS 15.2 or later.
