## ChatGPT

- ChatGPT can now use AnyRec's tools. Its connection request was refused before, so ChatGPT never saw them.

## Restart offered

- Claude Desktop and ChatGPT only pick up a new connection when they start. If one of them was already open when you connected it, Settings › AI Apps now offers **Restart**.

## Downloads

- **AnyRec-0.8.1.zip**: Mac app for Apple Silicon and Intel.
- **anyrec-0.8.1-universal.tar.gz**: command-line tool with its embedded Whisper framework.
- **SHA256SUMS**: checksums of both downloads.

Both downloads are Developer ID signed and notarized. Requires macOS 15.2 or later.
