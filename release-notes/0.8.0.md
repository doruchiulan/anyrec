## Connect AI apps from Settings

- **Settings › AI Apps** connects Claude Code, Claude Desktop, and ChatGPT and Codex to your recordings with one button each, so you can ask them about your meetings. The connection is read-only.
- **Copy Configuration** gives you the setup for any other app that supports MCP.
- The app itself serves the connection, so installing the app is enough; the command-line tool is not needed.
- Only AnyRec's own entry is changed in each app's settings file; everything else in it is left alone.

## Downloads

- **AnyRec-0.8.0.zip**: Mac app for Apple Silicon and Intel.
- **anyrec-0.8.0-universal.tar.gz**: command-line tool with its embedded Whisper framework.
- **SHA256SUMS**: checksums of both downloads.

Both downloads are Developer ID signed and notarized. Requires macOS 15.2 or later.
